# Smart Student Success Prediction System

## Project Description
This project predicts student performance using Machine Learning.

## Technologies Used
- Python
- Machine Learning
- Random Forest Classifier
- SQLite Database

## Features
- Enter student academic details.
- Predict student success.
- Save student prediction records.
- View student records.

## How to Run
1. Install the required Python packages.
2. Run the web application.
3. Open the application in your browser.# smart-student-success-prediction
